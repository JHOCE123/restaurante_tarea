**Asignatura:** Programación Orientada a Objetos

## Descripción
Sistema modular en Python para la gestión de un restaurante utilizando POO, separación en capas (modelos y servicios) y buenas prácticas de tipado estático.

## Estructura del Proyecto
- `restaurante_tarea/modelos/` (Contiene producto.py y cliente.py)
- `restaurante_tarea/servicios/` (Contiene restaurante.py)
- `main.py` (Punto de entrada del programa)

## Tipos de Datos Aplicados
- Básicos: `str` (texto), `int` (enteros), `float` (decimales), `bool` (booleanos).
- Compuestos: `list` (para almacenar colecciones de objetos).
